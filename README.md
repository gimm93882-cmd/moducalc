# 복리 계산기

원금과 회차당 수익률로 복리를 계산합니다.

- **레버리지 환산** — 가격 변동률 × 배수 − 수수료 = 회차당 순수익률. 청산선도 함께 표시합니다.
- **목표 금액 역산** — 목표까지 몇 회차인지, 정한 기간에 맞추려면 회차당 몇 %가 필요한지 계산합니다.
- **승률 보정** — 승률과 손실 폭을 넣으면 기하평균 기준 기대값으로 다시 계산합니다.

입력값은 브라우저에만 저장되며 서버로 전송되지 않습니다.

## 고지

계산 결과는 입력값에 대한 산술 결과일 뿐이며 특정 투자의 수익을 예상하거나 보장하지 않습니다.
실제 매매에는 슬리피지·펀딩비·청산이 발생하고 이 계산기는 그것을 반영하지 않습니다.

## 수정

`index.html` 은 직접 고치지 말고 원본에서 다시 생성합니다.

```
python3 -m tools.build_page ../복리계산기/index.html
```
